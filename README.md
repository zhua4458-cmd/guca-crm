# Guca CRM v2.0.0

外贸 CRM 完整版独立源码（不是设计稿，不是原型）：工作台、线索、商机 Kanban、客户、
跟进提醒、产品报价、订单全流程、财务、库存价目、全渠道收件箱 + 聊天、AI 获客、
营销、售后、资料库、日历、独立站对接、自定义、自动化、中英文切换。

## 技术栈

Node 18+ 内置 http/fs/path，零依赖、零 npm 构建、零框架。
数据存 `data/db.json`（首次启动从 `data/seed.json` 复制），可换 MySQL。
内存占用 < 50 MB，2 vCPU / 2 GB 服务器可跑。

**注意：这个仓库是哪个版本**
这是按 Muse 里在线用的 Guca CRM（截图里那个浅色完整版）重新写的独立源码，
功能对标那个版本。Muse 托管版的代码在 Muse 空间里，不能直接导出，
所以这里是一份重新实现的同款源码，不是从托管版拷出来的文件。

## 运行

```bash
node server.js
# 打开 http://127.0.0.1:3000
```

端口可用 `PORT=8080 node server.js` 改。
一键安装（服务器上 root 跑一条命令，自动装 Node、装服务、开 8080 端口）：

```bash
curl -fsSL https://raw.githubusercontent.com/zhua4458-cmd/guca-crm/main/install.sh | sudo bash
```

华为云 / 阿里云等还需在控制台安全组里放行 TCP 8080，本机命令开不了安全组。

## 功能

- 工作台：KPI 卡片（可拖拽排序、多页桌面、小部件抽屉）、AI 每日简报、销售漏斗、
  国家分布、SLA 逾期、今日待办、最近订单、未读聊天
- 线索：筛选、A/B/C 评级 + 自动打分、SLA 时钟（逾期标红）、转客户、CSV 导入导出、
  保存视图、批量操作
- 商机：Kanban 拖拽改阶段（询盘/需求确认/报价/谈判/样品/赢单/输单），阶段可改名、
  改赢单率、隐藏
- 客户：联系人、一页详情、跟进 + 聊天时间线
- 产品报价：产品库、多版本报价单、报价转商机转订单
- 订单全流程：备货进度、质检、验货、装箱、发货物流、定金/尾款分阶段收款、
  PI/装箱单/原产地证按订单数据生成
- 财务：应收/已收/逾期、月度趋势
- 库存价目：现货/在途/安全库存、缺货标红、出入库流水、阶梯价（数量→单价，
  USD/CNY/EUR）、下单自动扣库存、不足警告
- 全渠道收件箱 + 聊天：WhatsApp、邮件、独立站访客、Instagram、Messenger、企业微信；
  来信自动识别 16 种语言，时间后带小字语言标签，气泡下自动出中文译文；
  回信打中文，预览翻译成对方语言再发，气泡下附中文原文；
  草稿按会话保存，切换会话/页面/刷新都在；
  AI 建议回复按真实库存价目起草（只给草稿，不自动发），中文版 + 推理 + 依据只给你看
- AI 获客：15 家 OpenAI 兼容服务商预设、14 个海外媒体/购物平台、匹配度/意向分、
  一键导入（去重）、挖掘记录
- 营销：分群、邮件营销（模拟发送，开信/点击统计）、内容排期
- 售后：工单（咨询/投诉/退货/回访）状态流转；资料库（带版本）；日历月视图
- 独立站对接：生成/停用 API Key（guca_ 开头）、嵌入表单代码、JSON API 文档、
  询盘接收日志、一键测试（真走验证 + 建线索）
- 自定义：12 套主题配色 + 自定义颜色、圆角/密度/字号；20 种自定义字段类型；
  自定义对象（无代码）；角色权限（销售只能看自己的，金额隐藏）；
  布局导入导出；列表大标题彩色计数气泡（可点改色）；侧栏分组折叠/排序/改名
- 中英文切换：全站共用一张中英文案表，切英文后界面无中文残留（用户录入的数据除外）
- 自动化：8 条预设规则（SLA 逾期、报价过期、逾期收款、VIP 节日回访等）+ 执行日志；
  审计日志

## 数据

`data/seed.json` 是空库：首次启动就是空的，没有演示数据，自己加。
正式用之前不用清库。

## 仍是占位，需真实凭证才能接通

- WhatsApp / 企业微信：没有真实账号连接，消息是本地时间线模拟；
  接 WhatsApp Cloud API 需要 token + phone_number_id，企业微信需要 corp id + secret
- AI 翻译 / AI 回复 / AI 获客：没配 API Key 时走内置词典/演示引擎，
  界面会明确标注“演示”，不会伪装成真 AI；配了 Key 之后本版本仍用演示引擎兜底，
  需在 AI 设置里填对应服务商的 Base URL 才能走真实调用
- 邮件发送：营销邮件是模拟发送（只记开信/点击），未接真实邮件服务
- 翻译词典：内置 30 句常用外贸短句 × 10 语种，未命中返回原文并标注
